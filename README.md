# 纸序 PDF

**免费、开源、离线的 Windows PDF 工具箱。** 阅读、整理、打印、压缩加密、格式转换，一个窗口搞定。

文件只在你的电脑上处理，不上传文档、不用登录。自动检查更新默认开启，每天最多自动向 GitHub 查询一次版本，可在“关于”中关闭。

## 快速开始

1. 到 [Releases](https://github.com/d8349565/pdf-manage/releases/latest) 下载并运行 `ZhiXuPDF-Setup.exe`。首次使用文字识别时，另行下载 [OCR 增强包](https://github.com/d8349565/pdf-manage/releases/download/v0.10.1/ZhiXuPDF-OCR-win-x64.zip) 并导入；已安装兼容的旧包可继续使用，无需因主程序升级重装。
2. 把 PDF 或 OFD 拖进窗口，也可以点击“打开 PDF / OFD”。
3. 在“阅读”里看，在“整理”里改，完成后点“保存”；想保留原文件就点“另存为”。

提供绿色版附件的版本，也可下载 `ZhiXuPDF-Portable-vX.Y.Z.zip`，完整解压到独立且可写的文件夹，再运行其中的 `ZhiXuPDF.exe`。请保留 `_internal` 和 `portable.ini`，不要解压到安装版目录里。绿色版的设置、缓存及默认 OCR 组件放在自己的 `Data` 中，与安装版分开；发布包不包含个人 `Data`。

绿色版右键菜单默认关闭，可在“文件 → 右键快捷工具”中一键启用、修复或移除，菜单名称带“绿色版”。移动整个文件夹后可点“修复”；复制出的另一份绿色版不会接管原目录的菜单。删除前先移除菜单并关闭程序。安装版沿用原有的安装和右键注册方式。

> 如果想自己运行源码或参与开发，请参考 [开发说明](docs/DEVELOPMENT.md)。

| 压缩与加密 | 缩小体积；打开密码、免密阅读权限保护或双重保护 |
| 页码 | 添加可见页码、跳过封面、奇偶页外侧；阅读器页标签与批量输出 |

## 使用前请注意

- **图片右键快捷工具**：安装时勾选“启用右键快捷工具”，即可右键 JPG、PNG、WebP、BMP、TIFF 图片，选择“合并为 PDF”或“压缩图片”。多选图片会进入同一个合并窗口，默认按文件名自然排序，可拖动或用上移、下移调整，点击“合并并打开”后生成一个 PDF 并自动打开；多帧 TIFF 按帧展开。结果保存在首张图片旁边，同名文件自动避让；打开失败可点“打开 PDF”重试。Windows 11 中入口可能在“显示更多选项”里。压缩保留图片尺寸：PNG/BMP 自动比较无损 PNG 与 WebP，选择更小的格式；PNG 专有颜色、文字信息和高位深图片保留为 PNG，TIFF 使用无损优化，JPG/WebP 适度降低编码质量。还想进一步缩小，可点“更小体积（有损）”另存 WebP，可能改变小字、颜色和纹理细节；需要 PNG/JPG 格式的网站可能不接收 WebP。原图与已生成结果均保留，没有更小结果时不重复生成文件；多帧或动态图片暂不直接压缩。
- **复制页面**：在左侧页面栏或“整理页面”选中一页、多页，按 Ctrl+C / Ctrl+V 或右键复制粘贴；按住 Ctrl 拖动也可复制到落点，普通拖动继续调整顺序。页面副本可分别旋转、删除和编辑，Ctrl+Z 整批撤销；同窗口其他标签也能粘贴，来源标签关闭后仍可使用，关闭窗口后复制记录失效。
- **小册子打印**：在“文件 → 打印”的“排版方式”选择“小册子（对折装订）”，可选左右装订。页数不足 4 的倍数时自动补空白，预览显示每张纸正反面的页码与对折线；可用自动双面，或分两次打印正面、反面。手动双面需按打印机进纸方向放回纸张，必要时选择相反纸张顺序，请先少量试打；原 PDF 不变。
- **程序内图片压缩**：从“转换 → 压缩图片”选一张图片即可处理，无需先打开 PDF 或启用右键菜单；“转换 → 图片转 PDF”也可直接使用。

- **OFD 发票与回单**：通过“打开 PDF / OFD”或拖入文件查看、预览和打印；打开时在本机生成 PDF 工作副本，显示处理进度并可取消。保存会要求另存为 PDF，不能覆盖 OFD 原件。首版支持常规文字、矢量框线、图片、模板页和带外观的注释（水印、图片印章）；字体替代会提示核对。数字签名型 OFD、使用权限声明、多文档文件包、复杂裁剪、渐变、组合字形及部分特殊图片格式暂不支持，会提示原因并停止转换；不提供 OFD 签名验证和 OFD 格式回写。

- **阅读设置**：书本悬浮球固定在阅读区右下角，页面滚动时保持不动；短暂展示后贴边收起并保留小箭头，鼠标靠近时浮出。点击可选布局、适配方式或“本次运行隐藏悬浮球”。所有选项也可从“视图 → 阅读设置”找到；“视图 → 显示阅读悬浮球”随时恢复入口。临时隐藏只影响本次窗口运行，不保存到个人偏好，重新启动后恢复默认；切换或重新打开文档不会清除本次隐藏选择。
- **阅读缩放**：打开文档默认“适合页面”，当前整页完整显示；悬浮球或“视图 → 阅读设置”可切换适配方式，Ctrl+0 适合宽度。适配模式随窗口和页面尺寸变化调整；顶部加减或 Ctrl+滚轮进入手动缩放，百分比按 96 DPI 逻辑尺寸显示，100% 不表示适合宽度。
- **阅读布局**：从悬浮球或“视图 → 阅读设置”选择单页连续、双页对开或四页预览，Ctrl+1、Ctrl+2、Ctrl+4 也可直接切换。双页时，两页文档直接左右并排；较长文档封面居中，后续按 2–3、4–5 页对开，末尾偶数页留在左侧。四页按 2×2 排列，不足的位置留空。“适合页面”完整呈现当前组，滚轮按组翻页；适合宽度和手动缩放保留连续滚动。箭头、Alt+左右及 PageUp/PageDown 也可按组翻页，输入任意页码可定位所在组。切换保留当前页与手动缩放下的阅读位置；窄阅读区暂用单页，原因可在悬浮球提示或设置菜单中查看，展开后自动恢复原布局。
- **插入图片**：在审阅栏点击“插入图片”，选择 PNG/JPEG 后在当前页点击放置。选中图片后拖动位置、拉动边框控制柄调整大小，顶部圆形控制柄任意旋转；浮动条可输入宽、高（毫米）与角度，并切换锁定比例。尺寸调整以图片中心为基准，图片保持在页面内；Delete 删除，Ctrl+Z/Ctrl+Y 撤销/重做，Esc 取消当前拖动或退出选择。纸序插入的图片保存重开后仍可调整，不依赖原图片路径；单张限 10 MB、2000 万像素，暂不编辑文档中原有的普通图片。
- **整理放大预览**：按住 Alt 悬停在页面卡片上可查看清晰预览，松开或移出即关闭；也可右键选择“放大预览”，按 Esc 关闭。拖动排序时不弹出预览。
- **页面文本框**：在审阅栏悬停查看提示，选择“文本框”图标，画出范围后直接在页面内输入多行文字；拖动边框控制点可调整宽高，文字放不下时高度会自动增长。右下角可设置字体、字号和颜色。Enter 换行，点击框外或 Ctrl+Enter 完成，Esc 取消；双击已有文本框重新编辑，悬浮后可移动或删除。“改原文”用于修正已有单行文字，与新建文本框分开。
- **打印排版**：“每面排列”控制一面纸放几页；双面打印先排满正面再排背面。先横向/先纵向控制格子顺序，“相反页序”先反转所选 PDF 页序再排版。最后一面不足的格子留空。
- **灰度打印**：在打印窗口的“颜色模式”选择“灰度（黑白）”，预览和打印同步切换，彩色文字、图片及批注一起转为灰度，原 PDF 保留。重新打开打印窗口时默认彩色；实际用墨由打印机驱动决定。
- **页面选择**：左键单击选择一页；按住 Ctrl 再单击可加选或取消，按住 Shift 再单击可连续选择多页。滚动正文时保留多选范围。在“整理页面”按 Ctrl+A，或点击“全选”，可选中全部页面，高亮和已选页数同步更新；输入框中的 Ctrl+A 仍用于全选文字。
- **水印**：从“文档 → 水印”打开，左侧列表直接显示已有水印，并优先选中当前页的水印；点击对应条目可调整文字、图片和外观，或点击“删除所选水印”。要添加另一组水印，先点列表中的“＋ 新增水印”。勾选“整页平铺（重复多个水印）”可设置行数与每行个数，设为“自动”时按水印大小安排；手动调整数量不改变水印大小，过密可能重叠，单页最多 200 个，预览会显示当前数量。一次添加到多页的水印按一组管理，默认处理该水印所在页面，也可缩小页码范围。右侧自动更新预览，可拖动水印定位，平铺时整体移动图案，方向键微调，Shift 加大步长，拖动中 Esc 恢复起点，“复位”恢复居中。主页面不显示水印的批注浮框。应用后支持撤销；仅管理纸序添加的水印，保存重开后仍可选择。旧版水印会尝试恢复参数，无法恢复时可删除后重新添加。
- **PDF 右键入口**：安装时勾选 PDF 右键入口，可从资源管理器直接打开拆分设置或载入多个 PDF 合并。Windows 11 在“显示更多选项”中使用；先检查页面顺序，再保存为新文件。
- **Markdown 右键入口**：安装时勾选 Markdown 右键入口，右键 `.md` 或 `.markdown` 文件选择“转换为 PDF”，即可打开已填好文件的转换窗口。Windows 11 在“显示更多选项”中使用。
- **转换入口**：“转换”菜单上组为 Word、图片、Markdown 转入 PDF，下组为 PDF 转 Word、Excel、TXT、图片。转换窗口支持多文件拖入，默认保留原文件，已有输出默认跳过。
- **PDF 转图片版**：默认使用 200 DPI、JPEG 质量 90，兼顾清晰度与体积；需要更小文件可选择 150 DPI。200/300 DPI 无损图片适合优先保留像素细节，处理扫描件或带水印页面时可能明显增大文件。转换会固化水印、批注与表单外观，原件保留。
- **压缩 PDF**：默认“原画质”，逐张比较无损图片编码，并精简静态文档中未使用的字体字符；需要更小体积时，可选择高质量、均衡、适合外发、小体积，或自定义分辨率、质量及灰度。前后预览共用滚动和缩放，可连续查看全部页面；默认显示完整页面，Ctrl+滚轮放大、拖动查看细节，也可用缩放按钮和页码框。文字与矢量内容保留，结果另存副本；自动保留更小的结果。已充分压缩的 JPEG 可能没有明显无损收益，透明蒙版和部分特殊图片保留原编码。算法及生成样本验证见 [压缩说明](docs/COMPRESSION.md)。
- **页码输入**：英文逗号、中文逗号以及中英文分号均可分隔，例如 `1-3，5；7-9`。
- **插入页面**：在整理工具栏或页面菜单点击“插入页面”。已选页面时插入在最后一个所选页后，未选中时追加到末尾；插入后选中新页面，支持撤销、重做，保存时选择新文件以保留来源。
- **复制与粘贴页面**：在缩略图区或整理页面里选页，按 Ctrl+C，再到本文件或本窗口其他标签按 Ctrl+V。默认插到所选页后，也可先点击页面间隙确定落点；整批可撤销，源标签关闭后仍能粘贴。复制 PDF／图片文件或截图后，也可粘贴成新页面。关闭窗口后，内部页面复制记录失效；页内放图片仍使用插入图片功能。
- **扫描件增强**：从“扫描 → 扫描件增强”选择保留彩色或黑白打印，默认整页预览，可直接应用；需要时再对比原图、调整纸边或放大检查。更多设置收起，支持自动拉正、去底色及阴影减淡。增强页转为图片，文字层不保留，含批注、链接或表单的页不会直接处理；原件保留，可撤销并另存 PDF，也能导出当前页 PNG。
- **按页数拆分**：在拆分工具中选择“每几页一个文件”，输入页数后可看到预计文件数量；最后一个文件保留剩余页面。
- **页面大小**：在“整理页面 → 页面大小”或“页面 → 调整页面大小”中，默认选择 A4。可直接选 A3/A5/A6、B4/B5、16 开、Letter/Legal，并切换纵向或横向；选项标明毫米尺寸，B 系列区分 JIS/ISO，16 开提供 195×270 和 184×260 两种尺寸。也可匹配参考页或填写自定义宽高；匹配时预填所选范围前一页，没有前一页则需明确指定。内容等比缩放并居中，可能留白，其他页面不变；可撤销，保存时另存副本。已有印章随内容缩放，骑缝章需核对是否仍贴边；重新应用水印时按新纸张排版。
- **骑缝章**：在“文档 → 骑缝章”中导入 PNG/JPEG 印章图片，建议透明 PNG。默认只需选图、确认页面范围和印章大小，宽高自动保持比例；盖章边和沿边位置在“更多设置”中展开。完整图片按页码顺序分片，右侧滚轮连续查看上下页。已有骑缝章可整组调整范围、删除或撤销，保存重开后仍可管理；保存时另存副本。它属于图片外观盖章，不提供数字签名或验签。
- **批注裁剪**：用审阅栏的“矩形框”批注在页面上框出要保留的区域，再从“文档 → 批注裁剪”批量导出为新 PDF。排版可选“拼版排版”把多个区域流式排到 A4 便于打印，或“独立分页”让每页大小等于区域大小；同页多个批注可合并为一个区域，“页边距”来源无需批注、直接按每边内缩 36 磅裁剪。标记批注不会出现在结果里，隐藏的批注自动跳过；支持页码范围，未保存的批注也能参与裁剪，内容矢量保留、原件不变。
- **扫描纠偏**：在“扫描 → 扫描纠偏”中自动分析角度，右侧滚轮连续查看带水平参考线的上下页，左侧可逐页微调 ±10°；正数顺时针、负数逆时针。可靠且需要调整的建议默认勾选，不可靠建议需手动确认，空白页跳过。保留纸张尺寸并适度缩小补白，原始图片和已有可搜索文字层保留；可撤销，保存时另存副本，无需安装 OCR 增强包。含批注、印章或表单的页会跳过，请先纠偏再添加；不处理拍照透视或弯曲书页。含特殊命名跳转定位、文档自动动作或特殊页面单位的 PDF 暂不支持尺寸调整或纠偏，会提示原因。
- **单页分割**：在“整理页面”选中一页，点击“分割单页”，选择左右或上下分割、2 或 3 页，并按百分比调整分割线；可选等比适配 A4。分割后可拖动排序、撤销，再保存。原有批注和表单保留可见外观，但不再可编辑或填写；链接不再可点击。文档标题等信息和附件会随结果保存；无法保留的附加信息会先提示确认，并要求另存副本。加密文档分割后保存时需重新选择输出保护，并另存副本。
- **离线 OCR**：基础安装包不包含推理库或模型。在“扫描 → 文字识别（OCR）”中安装兼容的独立 OCR ZIP，之后无需 Python 和网络即可识别；已有兼容组件不随主程序升级而要求重装。输出新 PDF，支持页码范围、跳过已有文字与取消；金额、编号及识别结果请核对。[安装与使用说明](docs/OCR.md)
- **表格转 Excel**：支持电子 PDF 和完成 OCR 的扫描表格。线框、稳定对齐与浅色底纹用于推断行列；不规则或无明确证据的表格仍需核对。
- **Word 与 PDF 互转**：扫描 PDF 通过离线组件自动识别；已有 OCR 文字层可直接生成可编辑 DOCX，无需 Microsoft Word。普通电子 PDF 重排和 Word 转 PDF 使用本机 Microsoft Word，PDF 导入需要 Word 2013 或更高版本。只有需要 Word 导入时才询问首次确认设置。复杂版式仍需核对，加密文件需先另存解密副本。
- **Markdown 转 PDF**：使用 UTF-8 文件，支持常规 Markdown 和中文，仅加载同目录及子目录的普通本地图片，不访问远程图片、网络共享路径或链接文件。单张图片限 10 MB、2000 万像素；SVG 不加载外部引用。跳过图片会在转换结果中说明原因，公式和 Mermaid 按源码显示。
- **文字修正**：支持单行横排可见文字的原处修改，按 Enter 或确认图标应用，Esc 取消；右侧空间充足时可输入更长文字。应用时会实际移除旧字，写入失败保留原文和输入内容。选区与图片、表单、链接或隐藏文字重叠时拒绝修改，复杂段落请转 Word 编辑。
- **马赛克**：从“编辑 → 审阅与文字修正”进入，点击“马赛克”后在一页内框选。松开后选择像素块、柔化模糊或纯色遮盖，支持矩形、椭圆、强度和自选遮盖颜色；查看“选区效果”和“整页检查”后应用，Ctrl+Z 撤销，Ctrl+S 保存，下一次框选沿用本窗口上次应用的样式。框选矩形内的文字及底图会被替换，椭圆外围保留图片外观；相交批注、跨区图形可能整体移除，交互表单重叠时停止处理。像素块与模糊可能仍可辨认，敏感内容建议纯色；仅处理所选位置，不清理其他页面、附件或文档属性中的相同信息。
- **区域图片与批注分享**：从“编辑 → 框选导出图片”或审阅工具栏进入，也可按 Ctrl+Shift+C，在一页内拖动框选。预览后可复制整张图片或保存 PNG；原文在上，选区内有备注的批注在下方展开，并用编号对应，无需先逐条悬浮查看。没有备注的区域也能导出，Esc 或右键取消框选；复制权限限制继续生效，原 PDF 保留。
- **批注移动**：悬浮矩形框或便签后，拖动浮层的移动按钮即可实时预览落点；也可点击移动按钮再选位置。松手应用，Esc 取消，Ctrl+Z 撤销。
- **权限保护**：免密阅读的打印和复制限制依赖阅读器遵守，不能保证绝对防复制。
- **全文搜索**：点击顶部放大镜或按 Ctrl+F，输入关键词；Enter / F3 跳到下一处，Shift+Enter / Shift+F3 跳到上一处，Esc 关闭。搜索带文字层的页面，支持中文及英文字母大小写不敏感匹配；纯扫描图片需 OCR。长文档显示搜索进度，最多显示前 10,000 个匹配区域。
- **框选复制**：在阅读区拖动框选文字，按 Ctrl+C 或右键复制；正文命中可复制文字时显示文本光标。按住空格再拖动可临时移动页面，松开恢复原工具，也保留 Alt+拖动。输入框中的空格照常输入；电子文字和 OCR 文字使用同一交互，受复制权限限制。
- **暂不支持**：完整段落编辑、正文目录生成、手写识别及任意复杂版面的精确恢复。
- **请及时保存**：页面修改可撤销，但没有自动恢复草稿。带签名的文件会以只读方式保护。

# 使用指南

[返回项目首页](../README.md) · [OCR 安装与使用](OCR.md) · [压缩说明](COMPRESSION.md)

按实际操作查找说明。第一次使用请先看[快速开始](../README.md#快速开始)。

## 安装与快捷入口

### 安装版与绿色版

安装版运行 `ZhiXuPDF-Setup.exe`。绿色版完整解压到独立且可写的文件夹，运行 `ZhiXuPDF.exe`；保留 `_internal` 和 `portable.ini`，不要解压到安装版目录。绿色版的设置、缓存及默认 OCR 组件在自己的 `Data` 中，与安装版分开。

绿色版右键菜单默认关闭，可从“文件 → 应用设置 → 右键快捷工具”启用、修复或移除，菜单名称带“绿色版”。移动整个文件夹后需修复入口，复制出的另一份绿色版独立管理。删除程序前先移除已启用的菜单并关闭程序。

OCR 组件、任务缓存和默认输出位置可从“文件 → 应用设置 → 存储管理”查看或更改；迁移组件先复制并校验，原位置保留。完整规则见 [OCR 与文件位置说明](OCR.md#文件位置与空间管理)。

### PDF 右键入口

安装时勾选“启用右键快捷工具”，可从资源管理器直接打开拆分设置或载入多个 PDF 合并。Windows 11 在“显示更多选项”中使用；先检查页面顺序，再保存为新文件。

### 图片右键快捷工具

安装时勾选“启用右键快捷工具”，即可右键 JPG、PNG、WebP、BMP、TIFF 图片，选择“合并为 PDF”或“压缩图片”。多选图片会进入同一个合并窗口，默认按文件名自然排序，可拖动或用上移、下移调整，点击“合并并打开”后生成一个 PDF 并自动打开；多帧 TIFF 按帧展开。结果保存在首张图片旁边，同名文件自动避让；打开失败可点“打开 PDF”重试。Windows 11 中入口可能在“显示更多选项”里。压缩保留图片尺寸：PNG/BMP 自动比较无损 PNG 与 WebP，选择更小的格式；PNG 专有颜色、文字信息和高位深图片保留为 PNG，TIFF 使用无损优化，JPG/WebP 适度降低编码质量。还想进一步缩小，可点“更小体积（有损）”另存 WebP，可能改变小字、颜色和纹理细节；需要 PNG/JPG 格式的网站可能不接收 WebP。原图与已生成结果均保留，没有更小结果时不重复生成文件；多帧或动态图片暂不直接压缩。

### Markdown 右键入口

安装时勾选“启用右键快捷工具”，右键 `.md` 或 `.markdown` 文件选择“转换为 PDF”，即可打开已填好文件的转换窗口。Windows 11 在“显示更多选项”中使用。

### 查看更新内容

发现新版本后，点击窗口底部的“查看更新”，即可在软件内阅读本版的新增、优化和修复内容；也可从“关于 → 查看更新内容”随时打开。“使用前须知”可展开查看完整的使用限制和依赖说明。

更新说明取自 GitHub 发布页，获取后保存在本机；连接失败时可继续阅读已保存的同版说明，或点击“重新获取”。下载入口提供 GitHub 和蓝奏云，点击蓝奏云会复制提取密码。安装版下载后需关闭软件再运行安装包；绿色版下载同版 ZIP，退出软件后解压到新文件夹。

## 阅读

### 首页与最近阅读

首页右上角“打开文件”支持 PDF、OFD 和图片，也可直接拖入窗口。“最近阅读”最多显示 10 条，文件名下方显示所在位置，右侧显示上次阅读页码；单击即可继续阅读。点击“全部记录”或“文件 → 最近阅读记录”可查看最多 50 条记录、移除所选或清空记录，原文件保留；悬停可查看完整路径。

默认启动停留在首页；勾选“启动时继续上次阅读”后，下次直接打开软件会继续最近的文档。双击指定文件时优先打开该文件。记录仅保存在本机，不保存打开密码或未保存的修改；确定不存在的本地文件记录会在后台清理，暂时无法访问的磁盘、共享位置与权限不足的路径保留。

### 界面主题

点击工具栏右侧的“主题”，或打开“视图 → 界面主题”，可在石墨、远山、原版绿、赤陶和夜航之间切换。石墨是默认的灰白主题，原版绿保留新增主题前的青绿色、背景与交互配色，夜航是深色主题；每项旁边的色样可帮助选择。切换立即生效，并记住选择，下次打开继续使用。安装版和绿色版分别保存各自的主题设置。

主题只改变软件界面、图标和阅读区背景，PDF 页面、批注用色、打印和导出内容保持原样。

### OFD 发票与回单

通过“打开 PDF / OFD”或拖入文件查看、预览和打印；打开时在本机生成 PDF 工作副本，显示处理进度并可取消。保存会要求另存为 PDF，不能覆盖 OFD 原件。首版支持常规文字、矢量框线、图片、模板页和带外观的注释（水印、图片印章）；字体替代会提示核对。数字签名型 OFD、使用权限声明、多文档文件包、复杂裁剪、渐变、组合字形及部分特殊图片格式暂不支持，会提示原因并停止转换；不提供 OFD 签名验证和 OFD 格式回写。

### 阅读设置

书本悬浮球默认位于阅读区右下角，页面滚动时保持不动；短暂展示后贴边收起并保留小箭头，鼠标靠近时浮出。按住鼠标左键可拖到阅读区内其他位置，松手后停留并保持展开，窗口缩小时会限制在可见范围内；位置只在本次运行有效。点击可选布局、适配方式或“本次运行隐藏悬浮球”。所有选项也可从“视图 → 阅读设置”找到；“视图 → 显示阅读悬浮球”随时恢复入口。临时隐藏只影响本次窗口运行，不保存到个人偏好，重新启动后恢复默认；切换或重新打开文档不会清除本次隐藏选择。

先选择单页、双页或四页布局，以及“适合页面”或“适合宽度”，再点击“将当前视图设为默认”。之后新打开的文档沿用这个组合，重启后也保留；已经打开的标签保持各自的视图。手动缩放时，先切换到上述两种适配方式再保存默认。从“视图 → 界面恢复 → 恢复界面布局”可恢复为单页连续、适合页面。

按 F6 在阅读和整理页面之间切换；也可继续点击顶部的模式按钮。切换不修改 PDF 内容，已有默认阅读视图设置保留。

从“文件 → 应用设置 → 阅读快捷键”或“视图 → 阅读设置 → 阅读快捷键”修改模式切换、手形、文字选择和前后翻页的按键；也可为“进入阅读”“进入整理页面”单独指定按键。点击按键栏后按下新组合，保存时检查重复与保留按键冲突，支持清除、恢复默认并在重启后保留。

空格默认用于临时拖动；如果把空格设为翻页等动作，会停用空格拖动，仍可使用 Alt＋拖动。输入框中的空格继续正常输入。

### 阅读配色

从“视图 → 阅读设置 → 阅读配色”点击米色、浅绿或深色方案，即可在右侧预览当前页面。需要进一步调整时，点“自定义颜色”，分别选择纸面底色、文字颜色、页面外背景；“返回配色方案”可继续选择预设。点击“应用”后所有阅读标签沿用并记住选择；取消会还原打开设置前的配色。文字与纸面颜色太接近时，需要先调整才能应用。

配色按整页明暗映射，彩色图片、扫描文字和批注也会换色，不会单独识别或只修改文字。搜索命中、文字选区等操作提示继续单独显示。点击设置窗口中的“恢复原色”后应用，或选择“视图 → 阅读设置 → 恢复文档原色”，即可恢复。配色只影响阅读画面，不产生未保存修改，保存、导出、打印及整理页缩略图使用原色。

### 全屏与大纲侧栏

按 F11 或选择“视图 → 全屏阅读”进入全屏，自动切换到“适合宽度”，之后仍可手动缩放。再按 F11 或点击右上角“退出全屏”恢复窗口。Esc 优先结束当前选择、菜单或侧栏交互，再退出全屏；原文档和未保存的修改保留。

阅读时，左侧边缘的箭头可悬停或点击展开页面与大纲侧栏，F8 也可打开。离开后延迟收起；侧栏内有键盘焦点或正在操作菜单时保持展开，点击正文或按 Esc 可收起。取消“侧栏自动隐藏”可固定展开，此选项只影响当前窗口。Ctrl+Shift+B 直接打开大纲书签。

大纲会高亮当前阅读位置所属的章节，并展开所在层级。在大纲的“管理”或列表右键菜单中，选择“展开全部”或“折叠全部”可一次切换所有层级，只读文档也可使用。折叠全部后，阅读跟随只高亮可见的上级章节，不会自动打开折叠层级。

手动浏览目录时暂缓跟随；再次唤出侧栏会定位到当前章节，并尊重“折叠全部”的选择。同一页的多个条目有可靠位置时按页内位置判断，否则稳定选中该页第一个条目。正文不再弹出文字框选、复制和拖动的悬浮操作说明，这些操作仍可正常使用。

### 无边框模式

从“视图 → 无边框模式”或“视图 → 阅读设置 → 无边框模式”进入，也可按 Ctrl+F11 切换。窗口只显示页面，菜单、工具栏、标签、侧栏入口、悬浮球和滚动条都会隐藏；页面边线与阴影去掉，页面外背景跟随所选纸面底色，未启用阅读配色时使用白色。

按 Esc 退出并恢复界面；正在操作弹窗或菜单时，Esc 先关闭它们。进入时保留窗口大小并自动切换到“适合宽度”，F11 可另外切换全屏；滚轮、翻页和缩放快捷键继续可用。阅读页码、未保存修改、配色与原件保留；关闭最后一份文档会退出无边框模式并显示首页。

### 阅读缩放

未设置默认视图时，新打开的文档使用“单页连续”和“适合页面”，当前整页完整显示；悬浮球或“视图 → 阅读设置”可切换适配方式，Ctrl+0 适合宽度。适配模式随窗口和页面尺寸变化调整；顶部加减或 Ctrl+滚轮进入手动缩放，百分比按 96 DPI 逻辑尺寸显示，100% 不表示适合宽度。

单页连续阅读遇到大小不同的页面时，使用统一适配倍率，跨页滚动不重新缩放或居中。较小页可能留白更多，可手动放大查看；调整窗口大小后仍会重新适配。

### 阅读布局

从悬浮球或“视图 → 阅读设置”选择单页连续、双页对开或四页预览，Ctrl+1、Ctrl+2、Ctrl+4 也可直接切换。双页从第 1–2、3–4 页依次并排，末尾未配对的一页保留在同一阅读组。四页按 2×2 排列，不足的位置留空。“适合页面”完整呈现当前组，滚轮按组翻页；适合宽度和手动缩放保留连续滚动。箭头、Alt+左右及 PageUp/PageDown 也可按组翻页，输入任意页码可定位所在组。切换保留当前页与手动缩放下的阅读位置；窄阅读区暂用单页，原因可在悬浮球提示或设置菜单中查看，展开后自动恢复原布局。

### 全文搜索

点击顶部放大镜或按 Ctrl+F，输入关键词；Enter / F3 跳到下一处，Shift+Enter / Shift+F3 跳到上一处，Esc 关闭。搜索带文字层的页面，支持中文及英文字母大小写不敏感匹配；纯扫描图片需 OCR。长文档显示搜索进度，最多显示前 10,000 个匹配区域。

### 链接跳转

阅读时，鼠标移到 PDF 自带的链接上会显示手形和目标提示，单击即可跳转：网页由系统默认浏览器打开，邮件地址由默认邮件应用打开，文档内链接定位到当前文档中的目标页和位置。拖动链接文字仍可框选复制；整理页序后按目标页的新位置跳转，目标页已删除时会提示。

仅识别 PDF 已有的链接，普通文字网址和扫描图片不自动变成链接。指向本地文件、其他文档或执行程序的链接暂不打开；使用批注、图片编辑或区域截图工具时，点击优先操作当前工具。

### 框选复制

“视图 → 阅读设置”提供“选择文字”和“手形拖动”，顶部工具栏不常驻显示这两个按钮。在阅读区按 V 选择文字、按 H 切换手形；手形模式可直接拖动，不必一直按住空格。工具选择会记住，切换文件或重启后继续使用；单击链接仍可跳转，拖动时不打开链接。这两个快捷键只在阅读区生效，也可在“阅读快捷键”中修改。

在阅读区拖动选择文字，按 Ctrl+C 或右键复制；正文命中可复制文字时显示文本光标。从首行中间开始跨行拖选时，首行选到行尾，中间行完整选中，末行从行首选到终点；也支持反向拖选。按住空格再拖动可临时移动页面，松开恢复原工具，也保留 Alt+拖动。输入框中的空格照常输入；电子文字和 OCR 文字使用同一交互，受复制权限限制。

## 页面整理

### 页面选择

左键单击选择一页；按住 Ctrl 再单击可加选或取消，按住 Shift 再单击可连续选择多页。滚动正文时保留多选范围。在“整理页面”按 Ctrl+A，或点击“全选”，可选中全部页面，高亮和已选页数同步更新；输入框中的 Ctrl+A 仍用于全选文字。

### 整理放大预览

按住 Alt 悬停在页面卡片上可查看清晰预览，松开或移出即关闭；也可右键选择“放大预览”，按 Esc 关闭。拖动排序时不弹出预览。

### 插入页面

在整理工具栏或页面菜单点击“插入页面”。已选页面时插入在最后一个所选页后，未选中时追加到末尾；插入后选中新页面，支持撤销、重做，保存时选择新文件以保留来源。

### 复制与粘贴页面

在左侧页面栏或“整理页面”选中一页、多页，按 Ctrl+C / Ctrl+V 或右键复制粘贴；按住 Ctrl 拖动可复制到落点，普通拖动继续移动。多页保持原顺序，副本可分别旋转、编辑和删除，整批支持撤销、重做。默认粘贴到所选页后，也可先点击页面间隙指定位置；同窗口其他标签也可粘贴，来源标签关闭后仍能使用。复制 PDF、图片文件或截图后，也可粘贴成新页面；页内放图片仍使用“插入图片”。关闭窗口后，内部页面复制记录失效。

### 合并已打开文件

当前窗口打开至少两份 PDF 时，标签栏右侧会显示“合并”；也可从“页面 → 合并已打开文件”进入。默认按标签顺序勾选可合并的文件，可取消不需要的文件，拖动或使用“上移／下移”调整本次顺序，再点击“合并并另存”。列表会显示页数、未保存修改和不能合并的原因。

结果使用各标签当前的页面顺序、旋转、批注和书签修改，另存为新 PDF 并打开新标签。原文件、原标签顺序、阅读位置和未保存修改保留；不能覆盖任何已打开的来源文件。取消保存位置后仍留在选择窗口，处理中可取消，失败不提交半成品。首期支持 PDF 标签，OFD 和单独打开的图片请先另存为 PDF；原有“合并文件”仍用于从磁盘选择文件。

### 按页数拆分

在拆分工具中选择“每几页一个文件”，输入页数后可看到预计文件数量；最后一个文件保留剩余页面。

### 页码范围

拆分、提取等工具的页码范围支持英文逗号、中文逗号及中英文分号，例如 `1-3，5；7-9`。

### 单页分割

在“整理页面”选中一页，点击“分割单页”，选择左右或上下分割、2 或 3 页，并按百分比调整分割线；可选等比适配 A4。分割后可拖动排序、撤销，再保存。原有批注和表单保留可见外观，但不再可编辑或填写；链接不再可点击。文档标题等信息和附件会随结果保存；无法保留的附加信息会先提示确认，并要求另存副本。加密文档分割后保存时需重新选择输出保护，并另存副本。

### 页面大小

在“整理页面 → 页面大小”或“页面 → 调整页面大小”中，默认选择 A4。可直接选 A3/A5/A6、B4/B5、16 开、Letter/Legal，并切换纵向或横向；选项标明毫米尺寸，B 系列区分 JIS/ISO，16 开提供 195×270 和 184×260 两种尺寸。也可匹配参考页或填写自定义宽高；匹配时预填所选范围前一页，没有前一页则需明确指定。内容等比缩放并居中，可能留白，其他页面不变；可撤销，保存时另存副本。已有印章随内容缩放，骑缝章需核对是否仍贴边；重新应用水印时按新纸张排版。

## 审阅与编辑

### 页面文本框

在审阅栏悬停查看提示，选择“文本框”图标，画出范围后直接在页面内输入多行文字；拖动边框控制点可调整宽高，文字放不下时高度会自动增长。右下角可设置字体、字号和颜色。Enter 换行，点击框外或 Ctrl+Enter 完成，Esc 取消；双击已有文本框重新编辑，悬浮后可移动或删除。“改原文”用于修正已有单行文字，与新建文本框分开。

### 文字修正

选择“改原文”，点击一行或框选同一行中的部分文字，即可修改内容，也可以不改文字、直接调整样式。选区旁的紧凑工具条可选择本机字体、字号（6～144 pt）、加粗、斜体和颜色；字体框支持输入名称搜索，列表可滚动选择。设置作用于当前框选的已有文字，未调整的属性沿用原样式；混合样式在编辑时保留不同字号和颜色，点击回转箭头“恢复原样式”可取消本次样式设置。按 Enter 或确认图标应用，Esc 取消，应用后 Ctrl+Z 撤销。明确选择的字号不会自动缩小，空间不足或会挤到其他内容时提示调整并保留输入。

支持单行横排可见文字；右侧空间充足时可输入更长文字。同一行含不同字体、字号或颜色时也可直接修改，默认尽量保留未改文字的样式；替换文字按原位置分配样式，新增文字沿用前一个字的样式，行首新增则沿用第一个字的样式。原字体缺少新字时会尝试替代字体，未手动设置样式时可能微调字号；大幅改写后请核对样式。应用时会实际移除旧字，写入失败保留原文和输入内容。选区与图片、表单、链接或隐藏文字重叠时拒绝修改，复杂段落请转 Word 编辑。

### 插入图片

在审阅栏点击“插入图片”，选择 PNG/JPEG 后在当前页点击放置。选中图片后拖动位置、拉动边框控制柄调整大小，顶部圆形控制柄任意旋转；浮动条可输入宽、高（毫米）与角度，并切换锁定比例。尺寸调整以图片中心为基准，图片保持在页面内；Delete 删除，Ctrl+Z/Ctrl+Y 撤销/重做，Esc 取消当前拖动或退出选择。纸序插入的图片保存重开后仍可调整，不依赖原图片路径；单张限 10 MB、2000 万像素，暂不编辑文档中原有的普通图片。

### 批注移动

悬浮矩形框或便签后，拖动浮层的移动按钮即可实时预览落点；也可点击移动按钮再选位置。松手应用，Esc 取消，Ctrl+Z 撤销。

### 区域图片与批注分享

从“编辑 → 框选导出图片”或审阅工具栏进入，也可按 Ctrl+Shift+C，在一页内拖动框选。预览后可复制整张图片或保存 PNG；原文在上，选区内有备注的批注在下方展开，并用编号对应，无需先逐条悬浮查看。没有备注的区域也能导出，Esc 或右键取消框选；复制权限限制继续生效，原 PDF 保留。

### 马赛克

从“编辑 → 审阅与文字修正”进入，点击“马赛克”后在一页内框选。松开后选择像素块、柔化模糊或纯色遮盖，支持矩形、椭圆、强度和自选遮盖颜色；查看“选区效果”和“整页检查”后应用，Ctrl+Z 撤销，Ctrl+S 保存，下一次框选沿用本窗口上次应用的样式。框选矩形内的文字及底图会被替换，椭圆外围保留图片外观；相交批注、跨区图形可能整体移除，交互表单重叠时停止处理。像素块与模糊可能仍可辨认，敏感内容建议纯色；仅处理所选位置，不清理其他页面、附件或文档属性中的相同信息。

## 扫描与文字识别

### 去除彩色笔迹

从“扫描 → 去除彩色笔迹”进入。适合白纸、黑色印刷文字与红蓝笔迹的试卷、讲义或扫描件；全程在本机处理，不上传文件，无需 OCR 增强包。

1. 点击“红色”或“蓝色”即可生成清理预览；“取色”可点击原图中的其他彩色笔迹。上方的“原图／清理后”随时对比，普通操作不用调整算法参数。
2. “处理页码”默认整份当前文档，也可选当前页、原工作区所选页或指定页码，例如 `1-3，5`。使用左右翻页检查双页文档；A3 保持原来的尺寸和方向。“适合页面”“适合宽度”、加减按钮和 Ctrl＋滚轮用于查看，选“移动”或按住鼠标中键可拖动画布。
3. 点“擦除”，再选“画笔”“矩形”或“圆形”。画笔可直接涂抹，矩形/圆形拖出后只擦形状内部；笔刷默认直径 2 mm，放大查看不会改变在纸面上的实际大小。默认涂白，也可选“匹配纸面”；擦除会覆盖经过的内容，必须避开题目和符号。
4. 点“保留内容”，在原图上用相同的画笔、矩形或圆形标记不允许改动的部分，保护区始终优先。窗口内的“撤销／重做”和 Ctrl+Z／Ctrl+Y 按每笔操作恢复，换页保留各页标记。
5. 核对预览后点“另存清理副本”，选择新文件名。后台准备并写出，成功后打开副本，原文件和原工作区（包括未保存修改）保留；取消文件选择、取消处理或写入失败会保留当前清理窗口与标记，可继续编辑。每页都会重新计算识别区域，手工擦除只属于各自页面。

“调整效果”集中保存低频设置：颜色容差、浅色笔迹识别强度、平滑估计背景、粉色高亮的清除范围，以及只清理框选区域。“清除边缘残影（白纸打印）”默认开启，适合黑字白纸；照片、彩色底纸和很浅的灰线需核对，可关闭以沿用保守模式。“恢复默认清理参数”不清空手工标记；“清空本页手工修改”只作用于当前页并可撤销。“范围与保护区用于所选页”复制相对位置，三种手工擦除标记都不复制到其他页。

近黑笔尾与正文可能无法可靠自动区分，可用小笔刷补擦；独立的黑色手写不会被自动识别删除。画笔拖动时立即显示效果，松手后后台更新精确结果；匹配纸面的拖动预览采用估计背景色，最终以松手后的效果为准。

检测到 OCR / 隐藏文字层时，需明确选择保留或移除。保留时旧答案可能仍能搜索、复制；移除会删除实际处理页的**整页隐藏文字**，可见正文保留。隐藏文字与正文或表单交叠、无法安全移除时会停止整批处理。需要新文字层时，可在清理后另用“扫描 → 文字识别（OCR）”重新识别；本窗口不会自动重做 OCR，也不会声称已同步旧答案。

默认自动判断可清理的图片或原生批注。图片中的彩色笔迹按 RGB 像素识别；灰度图不自动去色，支持明确的手工擦除。原生文字、链接、书签和矢量保留；原生批注逐项勾选才删除，默认不勾选，碰到保护区的对象不列入删除候选。扫描图片上的其他独立批注保留，需要时可从“调整效果 → 处理内容”切换为只清理彩色批注。

首版不直接替换嵌套图形、透明蒙版、CMYK 等特殊色彩图片、同页重复使用的图片、特殊资源名或超过 2400 万像素的单张图片。压平的矢量笔迹不会被当作批注删除。确需处理时，明确选“转图片处理（原生文字将转为图像）”：仅所选页以最高 300 DPI、最长边 4200 像素转换，原生正文、矢量与文字层不保留，链接和独立批注保留，含表单的页暂不支持；页面尺寸、裁剪、方向和顺序保留。转图片会重采样，不能承诺在任意缩放下与原生 PDF 逐像素相同。

同色的红色印刷字、印章与手写笔迹无法可靠区分，务必使用预览、局部范围和保护区。保守模式可能留下很暗、很淡或交叉边缘的残色，不扩大颜色掩膜；残影清理会扩大到笔迹附近的背景，必须核对高亮范围。两种方式都不猜写被遮挡的文字；原图里完全被彩笔盖住的黑框或题目可能留下缺口，不能保证恢复。“平滑估计邻近背景”依据周围纸面估计填补颜色，不能恢复原稿；独立的黑色手写不属于本版范围。

后台处理有进度并可取消，关闭窗口也会取消在途预览；取消或失败不会留下被当作成功结果的部分文件。另存不能覆盖任何打开的来源，未选页面的内容保留。本功能用于打印前清理，不是安全脱敏工具，不保证清除历史版本或全部隐藏数据。

### 扫描件增强

从“扫描 → 扫描件增强”选择保留彩色或黑白打印，默认整页预览，可直接应用；需要时再对比原图、调整纸边或放大检查。更多设置收起，支持自动拉正、去底色及阴影减淡。增强页转为图片，文字层不保留，含批注、链接或表单的页不会直接处理；原件保留，可撤销并另存 PDF，也能导出当前页 PNG。

### 扫描纠偏

在“扫描 → 扫描纠偏”中自动分析角度，右侧滚轮连续查看带水平参考线的上下页，左侧可逐页微调 ±10°；正数顺时针、负数逆时针。可靠且需要调整的建议默认勾选，不可靠建议需手动确认，空白页跳过。保留纸张尺寸并适度缩小补白，原始图片和已有可搜索文字层保留；可撤销，保存时另存副本，无需安装 OCR 增强包。含批注、印章或表单的页会跳过，请先纠偏再添加；不处理拍照透视或弯曲书页。含特殊命名跳转定位、文档自动动作或特殊页面单位的 PDF 暂不支持尺寸调整或纠偏，会提示原因。

### 离线 OCR

基础安装包不包含推理库或模型。在“扫描 → 文字识别（OCR）”中安装兼容的独立 OCR ZIP，之后无需 Python 和网络即可识别；已有兼容组件不随主程序升级而要求重装。输出新 PDF，支持页码范围、跳过已有文字与取消；金额、编号及识别结果请核对。[安装与使用说明](OCR.md)

## 转换与压缩

### 转换入口

“转换”菜单上组为 Word、图片、Markdown 转入 PDF，下组为 PDF 转 Word、Excel、TXT、图片。转换窗口支持多文件拖入，默认保留原文件，已有输出默认跳过。

### Word 与 PDF 互转

PDF 转 Word 默认选择“保留原版式”，按原页位置生成可编辑文字和表格，色块、插图及批注印章保留外观，无需 Microsoft Word。扫描 PDF 需要离线识别组件；已有 OCR 文字层可直接导出。文字按位置编辑，大幅增删内容可能需要手动调整。

需要连续修改长段落时，在“更多选项 → Word 排版方式”选择“Word 重排”。普通电子 PDF 重排和 Word 转 PDF 使用本机 Microsoft Word，PDF 导入需要 Word 2013 或更高版本；只有需要 Word 导入时才询问首次确认设置。缺失字体、OCR 错字和复杂图文仍需核对，与图形重叠且无法可靠分离的局部文字会保留为图片。加密文件需先另存解密副本，签名文件需先明确制作可编辑副本。

### 表格转 Excel

支持电子 PDF 和完成 OCR 的扫描表格。线框、稳定对齐与浅色底纹用于推断行列；不规则或无明确证据的表格仍需核对。

### Markdown 转 PDF

使用 UTF-8 文件，支持常规 Markdown 和中文，仅加载同目录及子目录的普通本地图片，不访问远程图片、网络共享路径或链接文件。单张图片限 10 MB、2000 万像素；SVG 不加载外部引用。跳过图片会在转换结果中说明原因，公式和 Mermaid 按源码显示。

### PDF 转图片版

默认使用 200 DPI、JPEG 质量 90，兼顾清晰度与体积；需要更小文件可选择 150 DPI。200/300 DPI 无损图片适合优先保留像素细节，处理扫描件或带水印页面时可能明显增大文件。转换会固化水印、批注与表单外观，原件保留。

### 程序内图片压缩

从“文档 → 压缩 → 压缩图片”选一张图片即可处理，无需先打开 PDF 或启用右键菜单；“转换 → 图片转 PDF”也可直接使用。

### 压缩 PDF

默认“原画质”，逐张比较无损图片编码，并精简静态文档中未使用的字体字符；需要更小体积时，可选择高质量、均衡、适合外发、小体积，或自定义分辨率、质量及灰度。前后预览共用滚动和缩放，可连续查看全部页面；默认显示完整页面，Ctrl+滚轮放大、拖动查看细节，也可用缩放按钮和页码框。文字与矢量内容保留，结果另存副本；自动保留更小的结果。已充分压缩的 JPEG 可能没有明显无损收益，透明蒙版和部分特殊图片保留原编码。算法及生成样本验证见 [压缩说明](COMPRESSION.md)。

## 文档工具

### 水印

从“文档 → 水印”打开，左侧列表直接显示已有水印，并优先选中当前页的水印；点击对应条目可调整文字、图片和外观，或点击“删除所选水印”。要添加另一组水印，先点列表中的“＋ 新增水印”。勾选“整页平铺（重复多个水印）”可设置行数与每行个数，设为“自动”时按水印大小安排；手动调整数量不改变水印大小，过密可能重叠，单页最多 200 个，预览会显示当前数量。一次添加到多页的水印按一组管理，默认处理该水印所在页面，也可缩小页码范围。右侧自动更新预览，可拖动水印定位，平铺时整体移动图案，方向键微调，Shift 加大步长，拖动中 Esc 恢复起点，“复位”恢复居中。主页面不显示水印的批注浮框。应用后支持撤销；仅管理纸序添加的水印，保存重开后仍可选择。旧版水印会尝试恢复参数，无法恢复时可删除后重新添加。

### 骑缝章

在“文档 → 骑缝章”中导入 PNG/JPEG 印章图片，建议透明 PNG。默认只需选图、确认页面范围和印章大小，宽高自动保持比例；盖章边和沿边位置在“更多设置”中展开。完整图片按页码顺序分片，右侧滚轮连续查看上下页。已有骑缝章可整组调整范围、删除或撤销，保存重开后仍可管理；保存时另存副本。它属于图片外观盖章，不提供数字签名或验签。

### 权限保护

免密阅读的打印和复制限制依赖阅读器遵守，不能保证绝对防复制。

## 打印

### 打印进度

点击“打印”后立即显示进度窗口，准备期间显示当前步骤，发送时显示百分比和已处理的纸面数。一张纸的正面、反面分别计为一面；“每面排列”将多页放在同一面时，按排版后的面数统计。复杂页面会显示正在渲染的工作区页码。

最后显示“正在提交打印队列”，交给队列后结束任务。此进度不代表实际出纸；可以随时点击“取消任务”，已经交给打印机的页面可能仍会打印，需在系统打印队列中取消。

### 打印排版

打印窗口直接显示打印机、页码范围、纸张和方向、页面缩放、颜色、份数、排版方式及单双面。页边距、填充顺序、边框、相反页序和双面装订边在“更多设置”中展开。滚轮经过未展开的下拉框或份数框时，只滚动设置侧栏；点击、键盘选择和份数步进按钮仍可正常使用，打开候选列表后也可在列表中滚动。

在“打印范围”下选择“仅奇数页”或“仅偶数页”，可筛选全部页面、已选页面或指定页码范围。奇偶按当前文档从 1 开始的页码判断，例如范围 2–5 的奇数页为第 3、5 页；预览和用纸数量同步更新，没有匹配页面时不能打印。“相反页序”在筛选后生效；小册子的正反面仍通过小册子设置选择。

“页面缩放”默认“缩小过大页面”：小尺寸页面保持原大小，超出打印区域时才缩小，避免小发票放大铺满 A4。“适合纸张”会将页面放大或缩小以适应打印区域；“实际大小（100%）”不缩放，超出区域的部分不会打印，请先核对预览。多页排列时按每个格子的空间计算，小册子仍按对折排版适配格子。原大小以 PDF 页面的尺寸为准，不自动识别页面内发票图案的边界；原 PDF 不变。

在“普通打印”的“每面排列”选择“2 页（上下）”，纸张选择 A4，方向保持“自动”即可在一面纵向 A4 上依次放置两页，适合电子发票；第 1 页在上、第 2 页在下，原 PDF 保留。选择“2 页（左右）”时，自动使用横向纸张；也可按需要手动指定纸张方向。

“每面排列”还支持 1、4、6、9、16 页。双面打印先排满正面再排背面；“更多设置”中的先横向／先纵向只控制格子填充顺序，“相反页序”先反转所选 PDF 页序再排版。最后一面不足的格子留空，例如三页单面上下排列时，第二张纸只有上方一页。

### 灰度打印

在打印窗口的“颜色模式”选择“灰度（黑白）”，预览和打印同步切换，彩色文字、图片及批注一起转为灰度，原 PDF 保留。重新打开打印窗口时默认彩色；实际用墨由打印机驱动决定。

### 小册子打印

在“文件 → 打印”的“排版方式”选择“小册子（对折装订）”，可选左右装订。页数不足 4 的倍数时自动补空白，预览显示每张纸正反面的页码与对折线；可用自动双面，或分两次打印正面、反面。手动双面需按打印机进纸方向放回纸张，必要时选择相反纸张顺序，请先少量试打；原 PDF 不变。

## 保存与功能边界

### 签名与保护信息

打开“文档 → 签名与保护信息”可查看当前文档的签名检测结果、只读原因，以及按当前密码允许的打印、复制、修改等权限。合并文档可切换查看各个来源文件；选择签名或空白签名字段，可查看原文件页、当前文档页、署名、签署时间、原因与地点，点击“定位签名页”跳转。未能定位、没有保留该页或没有提供相应声明时，会明确显示。

署名和时间来自文件中的声明，不代表已经核实身份或可信签署时间。当前版本不解析证书详情，不验证签名有效性、文件完整性、证书信任、撤销状态或可信时间戳；图片印章和手写外观也不一定是数字签名。无法确认结构时，可查看下方检查说明；原件保护不会因打开此面板而解除。

面板底部可进入“制作可编辑副本”或“制作影像副本”，沿用现有权限检查和确认步骤，作用于整个当前文档；切换查看来源不会缩小副本范围。两类副本均不保留原数字签名验证结构，原文件保留。读取签名信息较多时显示进度并支持取消。

### 请及时保存

页面修改可撤销，但没有自动恢复草稿。带签名的文件会以只读方式保护。

“无法确认签名结构”表示签名检查未能可靠完成，并不代表已经确认文件有签名。为避免破坏可能存在的签名，原件不能直接合并或修改；可点击“制作影像副本”，用新副本继续合并。影像副本保留页面外观，但原文字层、可点击链接、可填写表单和数字签名不保留；需要搜索或复制文字时，可对副本进行 OCR。文件本身限制复制时，需要先提供管理密码。

### 暂不支持

完整段落编辑、正文目录生成、手写识别及任意复杂版面的精确恢复。

## v0.2.0 原验收记录

测试结果由验收人逐项勾选；未勾选表示尚未确认，不表示已经通过。

建议先使用随本次构建提供的合成材料。PDF 打开密码为 `read123`，管理密码为 `owner123`；这些密码仅用于测试材料。

## 准备

- [ ] P1：运行新版本 `ZhiXuPDF.exe`，在“关于”中确认版本为 **0.2.0**；程序目录中的 `_internal` 与 EXE 一起保留。
- [ ] P2：创建独立验收输出目录。使用合成文档或测试副本，记录系统版本、显示缩放比例和 Word 版本。

## 保护与格式转换

- [ ] E1：打开“电子文档.pdf”，选择“文件 → 加密另存 → 免密阅读”。限制打印、复制并设置管理密码。输出后能免密打开，打印和内容导出被限制；另用支持权限管理的阅读器核对。
- [ ] E2：选择“打开密码”模式，两次密码不一致时不能确认；正确设置后，重开文件必须输入打开密码。
- [ ] E3：选择“双重保护”，使用不同的打开密码、管理密码；相同管理密码不能确认。分别验证 AES-256 和 AES-128；AES-128 中文密码不能确认。
- [ ] W1：选择“文件 → 批量 PDF 转 Word”，加入“电子文档.pdf”。若出现首次启用提示，选择“否”应停止且不改 Word 提示设置；选择“是”才记住“不再重复确认”设置。
- [ ] W2：转换成功后在 Word 打开 DOCX，核对中文、金额 `12345.00`、页数和布局。修改文字后，用“批量 Word 转 PDF”转回 PDF，核对修改结果。**此项需要实机 Word 验收。**
- [ ] W3：分别转换扫描件和复杂版式。图片型页面不保证可编辑，复杂版式可能变化；确认提示清楚，结果可打开。
- [ ] W4：先在 Word 新建一份未保存的测试文档，再启动转换、取消转换。原 Word 窗口及测试内容应保留，任务结束后没有额外后台 Word 进程长期残留。
- [ ] W5：加入多份文件，保留一个同名输出。默认跳过同名输出；明确覆盖才覆盖。转换中取消，已完成文件保留，未完成输出不留损坏文件。加密 PDF 应提示先另存解密副本。
- [ ] M1：选择“文件 → Markdown 转 PDF”，加入“示例.md”。核对标题、中文、列表、表格、代码和本地图片，PDF 文字可搜索、复制。
- [ ] M2：核对缺失图片与网络图片警告。网络图片不下载；公式和 Mermaid 保留源码。
- [ ] M3：切换 A4 横向、字号与页边距，结果应变化。加入多份 Markdown，验证同名冲突、默认跳过、明确覆盖及取消。

## 页码与目录

- [ ] N1：打开“电子文档.pdf”，选择“文件 → 页码处理”。默认页脚居中，预览与输出一致，原文档不改动。
- [ ] N2：跳过封面，起始编号设为 1，使用“第 1 页，共 N 页”。封面不添加页码，总数为实际编号页数；改为起始编号 7 后顺序递增。
- [ ] N3：切换页眉、页脚、左中右位置及奇偶页外侧。使用“旋转裁剪.pdf”，确认所有页面均在预期位置，页码方向可读。
- [ ] N4：选择“仅设置阅读器页码标签”，跳过封面，使用罗马数字。输出正文不增加文字；重新打开后页面底部详情显示相应阅读器标签，也可用其他阅读器核对。
- [ ] N5：批量加入多个 PDF。每份从各自起始编号重新计数；已有输出默认跳过，失败文件有清楚说明。
- [ ] N6：对已有印刷页码的材料添加页码。新旧页码可能并存，软件不得声称已经自动清除旧页码。
- [ ] B1：选择“视图 → 大纲书签”（或侧栏切换），展开已有目录，点击能跳到对应页。
- [ ] B2：添加、重命名书签，设置子项、提升层级、删除含子项的节点。Ctrl+Z／Ctrl+Y 可撤销重做，保存重开后结构一致。
- [ ] B3：调整书签目标页的页面顺序，书签继续指向同一页面；删除该页后标示失效，撤销页面删除后恢复跳转。
- [ ] B4：合并“电子文档.pdf”和“无目录.pdf”，应以文件名建立一级节点，包括没有原目录的文件。

## 审阅与文字修正

- [ ] A1：点击“整理页面”旁的“审阅与文字修正”图标，拖选文字添加高亮、下划线。高亮为连续淡色底色，无逐字重叠接缝；扫描件没有文字层时应明确说明，仍可用画笔或便签。
- [ ] A2：添加便签，阅读模式下鼠标悬浮显示单个备注浮层，移开后收起；点击浮层编辑按钮或双击便签可修改备注，支持移动、删除。保存重开后备注内容可读取。
- [ ] A3：分别绘制画笔、矩形、椭圆、箭头。绘制时有实时预览；箭头尖头短小，预览与完成结果一致；颜色、线宽、方向正确，跨页拖动限制在当前页。
- [ ] A4：点选批注，应用新颜色／线宽，删除批注。Ctrl+Z／Ctrl+Y 可恢复；取消当前笔画或收起审阅后能正常拖动阅读。
- [ ] A5：旋转页面、放大缩小后再标注，位置与所选内容对应。添加、撤销批注时缩放和滚动位置保持不变，在 150% 显示缩放下无页面抖动；保存后用其他 PDF 阅读器检查原生批注。
- [ ] A6：合并同一来源文档两次，在其中一个页面添加批注，另一个副本不应跟着变化。
- [ ] T1：选择“单行文字修正”，点击或框选 `DATE2020` 并在原处改成 `DATE2026`。编辑框跟随缩放和滚动；Enter 或确认图标应用，Esc 或取消图标不修改；应用后可撤销重做。
- [ ] T2：保存重开，目标区域旧字不能再被复制／提取，新字能搜索；相邻 `KEEP`、线条、图片和其他批注保留。
- [ ] T3：右侧空余空间足够时允许输入更长文字，超出安全宽度时阻止应用并保留输入内容。跨行、混合样式、隐藏文字、扫描图片、表单／链接重叠区域应拒绝修正，并建议转 Word。
- [ ] T4：修改中文，核对缺字回退后的字形、字号、颜色和位置；含已有字体子集的 PDF 修改后整行仍可见。取消或写入失败时保留原文字，失败时保留输入内容供继续修改。
- [ ] T5：修改、保存，再撤销。撤销后的内容与未保存状态应正确；重新保存不得重复盖上相同批注或重复修正。

## 原有功能、稳定性与性能

- [ ] R1：合并、旋转、重排、删除、提取、拆分以及撤销重做可用；取消保存或目标冲突不损坏源文件。
- [ ] R2：电子 PDF 表格转 Excel、图片互转、压缩及打印预览可用。实际纸张、双面和打印机输出由验收人核对。
- [ ] R3：加密文档普通保存后仍保留密码与权限；只允许批注的文档可保存合法批注，不能因此修改原文或整理页面。
- [ ] R4：关闭有修改的文档应提醒保存；程序退出后完整输出保留，不长期积累临时文件和 Word 进程。
- [ ] R5：使用“长文档.pdf”连续翻页、滚动和缩放。阅读时不应反复卡顿；首次渲染有反馈，返回近期页面能复用缓存。
- [ ] R6：打开大纲、审阅、Markdown 转换前后分别观察响应和内存。普通阅读不应自动启动 Word 或扫描全文；多次编辑、保存后的内存不持续无界增长。
- [ ] R7：若有签名 PDF 测试副本，确认原件只读保护；“制作可编辑副本”有签名效力不保留的明确提示。

# PDF 压缩与对照预览

## 使用方式

“压缩 PDF”默认选择“原画质（推荐）· 无损优化”。点击“开始压缩”后，先看文件大小，再放大核对内容，最后另存副本。

预览使用一个滚动区域绘制左右两列。滚轮、水平滚动、拖动、页码跳转和缩放都作用于两侧的同一页、同一位置。默认适合页面，可切换适合宽度或指定比例；Ctrl+滚轮和加减按钮可以缩放，滚动可直接查看上下页。页面在后台按需加载，切换页码不再弹出进度窗口。

左侧来自应用工作区编辑后的原始快照，右侧来自实际压缩结果。原始快照与无损候选分别保存，避免把已经优化的文件冒充压缩前内容。档位改变后，旧结果不能导出；关闭会先取消预览进程，再释放临时文件。

## 压缩策略

1. 保留页面、文字、矢量、链接与目录，合并重复对象并压缩对象流。
2. 对普通灰度、RGB 及相应 ICC 颜色配置的图片，比较原编码与多种 PDF 编码：带行预测的 Flate、颜色完全相同的索引调色板、黑白 CCITT Group 4、无损 JPEG 2000。只有更小的候选才替换原图；调色板转换会逐像素核对，不做近似减色。
3. 静态文档对子集字体进行优化，只保留实际使用的字符。带可填写表单或批注的文档跳过这项新增字体优化，保留后续填写与编辑所需字体。
4. 高质量、均衡等档位仍允许降低图片分辨率及 JPEG 编码质量。共用图片按最大的显示尺寸计算分辨率；沿用原有原生缩放，JPEG 保留完整色彩采样，比较普通与渐进编码的大小。不会为压缩数字另加一层色彩降采样。
5. 无损完整分辨率候选、所选档位候选与原编码共同参与体积比较。最终整份文件仍与无损结果比较，没有进一步缩小时使用更小的无损结果；用户明确要求的灰度转换保留该选择。

透明蒙版、特殊 Decode 数组、CMYK 等暂不由逐图优化器重写。黑白像素页保留分辨率。无损 Pillow 处理限制为单图 2000 万像素；有损档位可先在原生引擎中把更大的扫描图缩小，再进入此范围，超过 1 亿像素或缩小后仍过大则保留原图。可选 JPEG 2000 编码失败时使用其他无损候选，来源文件不会被覆盖。

这是一组按图片内容择优的编码策略，收益取决于原始文件。完整内嵌字体、低效编码的表格和部分扫描页有改善空间；已经优化过的 JPEG 通常难以继续大幅无损缩小。默认“原画质”与其他有损档位应分开比较，不能把降低分辨率得到的缩小量称为同画质提升。

基础能力参考：[PyMuPDF 压缩说明](https://pymupdf.readthedocs.io/en/latest/compressing-files.html)、[Pillow 图片编码参数](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html)。产物使用 PDF 的 Flate、CCITT、JPX、DCT 标准过滤器。

## 独立图片压缩 · 2026-10-24

资源管理器右键图片 →“压缩图片”，自动在原图旁生成更小的副本。PNG/BMP 比较无损 PNG、精确调色板及无损 WebP；只有更小时才保存，并在结果中说明实际格式与是否有损。PNG 专有颜色块和文字信息保留在 PNG，高位深与超出 WebP 单边尺寸限制的图片不转 WebP；ICC、EXIF 继续保留，PNG 的 DPI 转存至 WebP 的 EXIF 分辨率字段。不同看图或打印软件对 WebP 分辨率字段的读取可能不同。

默认无损 WebP 使用 `lossless=True, quality=75, method=3, exact=True`，不使用近似减色；`exact` 保留全透明像素里的 RGB。无损 WebP 编码失败时保留已经得到的 PNG 候选。参数说明见 [Pillow WebP 编码选项](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html#webp)和 [WebP 编码参考](https://developers.google.com/speed/webp/docs/cwebp)。JPG/WebP 的原有快捷流程仍使用适度有损编码，TIFF 仍使用无损压缩；此处新增的无损择优只用于 PNG/BMP。

需要进一步减小时，点击“更小体积（有损）”，从原图生成质量参数 95、尺寸不变的 WebP，透明度仍使用无损编码。这个选项会改变颜色、纹理和小字细节，不能称为像素无损。特殊颜色模式、缺少 ICC 的 PNG 独立颜色信息及超限尺寸拒绝转换；新候选不小于原图或上一份结果时不创建额外文件。上一份结果和原图均保留，有损副本的文件名带“_更小”。WebP 的接收范围与 PNG/JPG 不同，请按上传网站或接收软件的格式要求选用。

44 项图片快捷工具与启动检查通过，新增生成场景覆盖复杂纹理与透明图片的无损像素、全透明区域的颜色、ICC／EXIF／DPI、16 位图片、超宽图片、候选编码失败、有损尺寸与透明度、PNG 颜色信息防丢失、单按钮二次处理，以及较大有损结果的回退。显示文件名与路径提示调整后，受影响的 3 项窗口检查再次通过。真实输入的图片和测试记录只保留在本地忽略目录，不进入项目文档或仓库。

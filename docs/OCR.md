# 纸序 PDF · OCR 文字识别使用说明

> 对应 v0.4.0 新增功能（ISSUE-07）。

## 1. 这是什么

OCR 文字识别把扫描件 PDF 转换为带"隐藏文字层"的 PDF，**保留原始扫描图像**，
让原本无法搜索、复制的扫描件也能在纸序 PDF 中：

- 使用 `Ctrl+F` 全文搜索；
- 选中文本并复制；
- 与电子文字层 PDF 同样操作。

整个识别过程：

1. 完全离线（不会上传文件）；
2. 在普通 Windows CPU 上运行（不需要独立显卡）；
3. 默认不修改原文件，输出独立副本 `<原文件名>_OCR.pdf`。

## 2. 安装 OCR 增强包

OCR 推理库（RapidOCR / ONNX Runtime）和模型权重（PP-OCR 系列）独立打包，
**不进入基础安装包**。首次使用 OCR 时：

1. 启动纸序 PDF → 工具 → OCR 文字识别；
2. 若弹窗顶部显示"未检测到 OCR 增强包"，按提示下载离线安装包；
3. 安装到 `%LOCALAPPDATA%\ZhiXuPDF\ocr\`（默认路径）；
5. 重新打开 OCR 弹窗，确认顶部不再显示警告。

> 安装包是独立 PyInstaller 产物，包含 `det.onnx / rec.onnx / cls.onnx / ppocr_keys_v1.txt / manifest.json`。
> 安装器会校验 SHA-256 与版本兼容性。

## 3. 使用步骤

1. 打开扫描 PDF；
2. 选择 **工具 → OCR 文字识别**；
3. 在弹窗中选择识别范围：
   - **当前页**：仅识别视图中当前页；
   - **全部页面**：识别整份文档（默认）；
   - **指定页码**：例如 `1-3,5,8`。
4. 识别策略默认勾选"跳过已有文字的页面"。
5. 确认输出文件路径（默认 `<原文件名>_OCR.pdf`，与原文件同目录）。
6. 点击 **开始识别**，等待进度弹窗完成。

识别完成后弹窗会显示：

- 已处理 / 跳过 / 失败页数；
- 输出文件位置；
- 失败原因（如果有）；
- "打开识别后的 PDF" 与 "打开文件夹" 两个入口。

## 4. 取消与重试

- 进度弹窗提供 **取消任务** 按钮；
- 取消后临时文件会被清理，**不会留下损坏的输出**；
- 可以重新打开 OCR 弹窗继续尝试。

## 5. 注意事项

| 场景 | 行为 |
|---|---|
| 当前 PDF 有未保存修改 | 弹窗询问是否继续；建议先保存避免处理过期文件 |
| PDF 已加密 / 需要密码 | 不会启动 OCR，请先解除加密 |
| PDF 含数字签名 | MVP 不处理，请使用未签名副本 |
| 输出文件已存在 | 默认重命名为 `<原名>_OCR_1.pdf`，不覆盖原文件 |
| 已有文字层页面 | 默认跳过，节省时间 |

## 6. 识别准确率

在 30 页合成办公样本（清晰中文 / 中英混排合同 / 数字金额报价单）上，
**归一化中文字符错误率 CER 显著低于 5%**。详见 `docs/ocr/ACCEPTANCE-REPORT.md`。

低分辨率（≤150 DPI）或严重倾斜的扫描件准确率会降低，可重新扫描提升质量。

## 7. 故障排除

| 症状 | 处理方式 |
|---|---|
| 弹窗显示"未检测到 OCR 增强包" | 安装增强包，或检查 `%LOCALAPPDATA%\ZhiXuPDF\ocr\` 是否被防病毒隔离 |
| 弹窗"OCR 增强包不完整" | 重新安装增强包 |
| 识别结果为空 | 增大渲染 DPI 或重新扫描；当前 MVP 固定 200 DPI |
| 搜索高亮位置偏移 | 属于已知精度问题，正在优化坐标变换 |
| 取消后弹窗卡住 | 关闭当前 PDF 重新打开即可 |

## 8. 隐私

- OCR 完全在本地进行，不向任何服务器发送文件；
- 不会缓存识别内容到磁盘（除最终输出 PDF）；
- 卸载 OCR 增强包即可彻底移除所有模型与依赖。
